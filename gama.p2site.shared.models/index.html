GAMA Shared Models

This is an Eclipse p2 update site. Add https://gama-platform.org/gama.shared.models/ in Help > Install New Software... and select GAMA Shared Models.

This initial scaffold contains empty logic and UI bundles. Browsing, importing and other runtime behavior are not implemented, and no GAML extensions are registered.

Baseline: Eclipse 2026-03, Java 21 or newer. Platform support: Linux GTK x86_64, Windows x86_64, and macOS x86_64 / Apple Silicon.

This thin site hosts only the two shared models bundles and their feature. Keep Eclipse 2026-03 enabled for external dependencies.
